# kelan — портфолио Александры Поповой

Одностраничное портфолио-резюме студентки направления «Прикладная информатика в дизайне».

## Запуск
Откройте `index.html` в браузере или через Live Server в VS Code. Сборка и установка пакетов не нужны.

## Технологии и функции
HTML, CSS, обычный JavaScript. Адаптивная вёрстка, фильтр проектов («Все», «Дизайн», «Мультимедиа»), переключение светлой/тёмной темы с сохранением в localStorage, мобильное меню (включая Escape), слайдер иллюстраций.

## Что заменить перед публикацией
- Контактный email `your-email@example.com` в `index.html`.
- Четыре демонстрационных проекта на настоящие работы, названия и изображения.
- `assets/gallery-01.svg` ... `gallery-04.svg` на собственные рисунки, обновив пути в массиве `slides` в `main.js`.
- При необходимости фотографию `assets/alexandra-cutout.png`.

## Публикация через GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `main.js`, `README.md` и папку `assets` в корень репозитория.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку `main`, папку `/ (root)` и нажмите Save.
5. Дождитесь появления адреса сайта в Pages. Для сдачи задания используйте ссылки на сайт и репозиторий.


## Обновление: отдельные страницы проектов и анимации

- `project.html?id=identity` — фирменный стиль; `?id=editorial` — редакционный дизайн; `?id=motion` — моушн-дизайн; `?id=3d` — 3D и персонажи. Страницы формируются из данных `projects.js`.
- В `projects.js` замените учебные описания на реальные. В поле `media` добавляйте материалы: `{type:"image",src:"assets/filename.jpg",caption:"Подпись"}` или `{type:"video",src:"assets/video.mp4",caption:"Видео"}`. Файлы помещайте в `assets/`.
- В `contacts.js` заполните `telegram` полной ссылкой `https://t.me/ВАШ_НИК`, а `tiktok` — `https://www.tiktok.com/@ВАШ_НИК`. Пока ссылки не заполнены, кнопки намеренно неактивны.
- Анимированы кнопки, карточки, ссылки, появление секций, первый экран, мобильное меню и переходы галереи. Учитывается `prefers-reduced-motion`.
- Для публикации загрузите все файлы в корень репозитория и включите GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
